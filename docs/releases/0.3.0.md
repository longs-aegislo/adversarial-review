# Adversarial Review Plugin 0.3.0

Plugin version: 0.3.0
Result schema: 1
Supported platforms: Linux; macOS; Windows via WSL
Host compatibility: Codex CLI 0.146.0 or later; experimental Plugin API

## External prerequisites

Bash, `jq`, Git, GNU-compatible timeout support, and authenticated Claude Code
and Codex CLIs are supplied by the operator. Installation does not provision
credentials, subscriptions, quota, or network access.

## Migration and compatibility

Use `./scripts/upgrade-plugin.sh` when upgrading a branch-tracking or pre-0.3
installation. It migrates legacy state before replacing the package. CLI result
schema 1, Skill workflow 1, and installation layout 1 remain compatible.

## Known limitations

The Codex Plugin API is experimental. Automated acceptance covers Linux plus a
Windows/WSL-style CRLF checkout; macOS and real authenticated backends require
a small manual release smoke test. Submission to a public universal Plugin
directory is outside this release.
